# OxideModMenu

A Kotlin Android floating-window UI demo for Android 10+ (target SDK 36).

## Build
GitHub Actions builds a debug APK on pushes to `main` or via Actions > Build Android APK > Run workflow.

Download the artifact named `OxideModMenu-debug`, then extract `app-debug.apk`.

## Install
Install the APK on your Android device. Open the app, grant "Display over other apps", return to the app, and tap "OPEN FLOATING MENU".

## Important
This is a standalone visual demo. Its switches only show their state and do not modify Oxide Survivor, game memory, network traffic, or gameplay.
